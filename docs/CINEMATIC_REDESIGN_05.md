## Implementation

`CompanyTeam` remains the shared server-rendered component on the official homepage, About page and authorized private presentation. It reads the canonical `companyTeam` list, containing only Ben Beya Mohamed (Fondateur) and Bouzrara Manel (Gérante). The introduction and closing line use existing company copy. The section has two large portrait panels, an asymmetric desktop offset, names and roles beneath each panel, and a short visual handoff to the next section. The panels stack in source order on mobile.

The new Team CSS uses existing display and color tokens, transparent section background, diffused forest-green and gold light, and restrained borders. The inherited site environment currently has navy tones; the Team keeps that continuous background and adds forest accents without a horizontal color band. No font was added.

The scoped `cinematicTeamStory` recipe runs inside the existing `MotionScene` GSAP context and responsive `matchMedia` lifecycle. On desktop and tablet, each member gets a scrubbed mask reveal, a small camera scale/pan and staggered name/role movement. The second mask opens from the opposite edge. ScrollTrigger reverses these changes on upward scroll. Desktop camera travel is at most 9 px and initial scale is 1.035; tablet uses 4 px and 1.015. Mobile uses one short opacity reveal. Static/reduced-motion mode keeps full content visible. The recipe creates no scroll state updates, pinning or perpetual loop; the existing motion owner restores inline styles on teardown and MotionToggle changes.

Portraits are rendered only when the existing authorized presentation passes `CompanyPortrait` props after session and hash checks. Its existing protected delivery URL and image dimensions are retained. The public site receives no portrait props and displays initials with “Portrait à venir”. The private files were not copied to `/public`, source, metadata or production output. Existing image optimizer, private production denial, access expiry and integrity checks were left intact.
